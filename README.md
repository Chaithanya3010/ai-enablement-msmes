# SHINE Foundation — AI Enablement for MSMEs

A React + Vite landing page using the AI Enablement for MSMEs programme information from the supplied I-Venture reference page, rebranded for SHINE Foundation.

## Run locally

1. Install Node.js 18+.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost URL Vite prints (normally http://localhost:5173).

## Important

Organisation-specific reference details such as the original partner names, emails and registration URL have intentionally not been presented as SHINE facts. Update the CTA/contact details and eligibility before publishing if SHINE is not running the exact same programme.
